# WhatsAppReminder — تطبيق تذكير رسائل واتساب

تطبيق Android يُذكّرك في الوقت المحدّد بإرسال رسالة واتساب، ثم تفتح المحادثة
بضغطة زر لتُرسلها **بنفسك**. التطبيق **تذكير فقط** ولا يُرسل تلقائياً.

---

## 🔒 فلسفة الأمان (مهمة)

- التطبيق يُذكّر فقط عبر إشعار في الوقت المحدّد.
- **أنت** من يفتح واتساب ويضغط زر الإرسال.
- **لا** يوجد `AccessibilityService`، ولا قراءة للشاشة، ولا أتمتة لواجهة واتساب.
- فتح واتساب يتم حصراً عبر رابط رسمي `wa.me` (Deep Link) بواسطة `Intent`.
- هذا التصميم يحمي حسابك من الحظر ويحترم شروط استخدام واتساب.

## 🚀 كيفية التشغيل

### 1) إنشاء/فتح المشروع في Android Studio
- افتح **Android Studio** (Hedgehog أو أحدث).
- اختر **Open** ثم اختر مجلد المشروع الجذر (حيث يوجد `settings.gradle.kts`).
- انتظر حتى يكمل Gradle المزامنة (Sync). سيقوم Android Studio بتنزيل التبعيات.

### 2) توليد Gradle Wrapper (إن لزم)
إذا لم يوجد `gradlew`, نفّذ من الطرفية داخل مجلد المشروع:
```bash
gradle wrapper --gradle-version 8.2
```
أو ببساطة دع Android Studio يتولّى ذلك تلقائياً عند فتح المشروع.

### 3) إعداد `local.properties`
Android Studio ينشئه تلقائياً. للتشغيل اليدوي أنشئ ملف `local.properties` في الجذر:
```properties
sdk.dir=/path/to/your/Android/Sdk
```

### 4) تشغيل التطبيق
- وصّل جهازاً حقيقياً (يُفضّل لاختبار الإشعارات) أو شغّل محاكياً بنظام Android 10+.
- اضغط **Run ▶**.
- عند أول تشغيل على Android 13+ سيطلب التطبيق **صلاحية الإشعارات** — اقبلها.

### 5) إعداد WorkManager + Hilt (مهم)
تم إعداده مسبقاً في المشروع:
- `WhatsAppReminderApp` ينفّذ `Configuration.Provider` ويزوّد `HiltWorkerFactory`.
- في `AndroidManifest.xml` عُطّلت التهيئة الافتراضية لـ WorkManager عبر `tools:node="remove"`
  حتى تعمل التهيئة المخصّصة مع Hilt. لا حاجة لأي خطوة إضافية.

## ⚙️ كيف يعمل التطبيق (السيناريوهات)

### 1. السيناريو الطبيعي
1. تضيف تذكيراً (اسم، رقم مع رمز الدولة، رسالة، وقت مستقبلي).
2. يُحفظ في Room وتُجدول مهمة `OneTimeWorkRequest` عبر WorkManager بتأخير = وقت التذكير.
3. عند حلول الموعد يعمل `ReminderWorker` → يعرض إشعاراً عالي الأهمية → الحالة `NOTIFIED`.
4. تضغط الإشعار → تُفتح شاشة التفاصيل → زر **فتح واتساب وإرسال** → الحالة `OPENED`
   وتُفتح محادثة `wa.me` مع الرسالة جاهزة → تضغط إرسال بنفسك.

### 2. الجهاز مغلق / بدون شبكة
- شرط `NetworkType.CONNECTED` يؤجّل العمل حتى تعود الشبكة.
- داخل العامل: إن كانت الشبكة غير متصلة → الحالة `PENDING_NETWORK` ثم `Result.retry()`
  مع Backoff تصاعدي، ويُعاد التنبيه فور عودة الاتصال.

### 3. فات الموعد
- إذا فات الموعد بأكثر من **24 ساعة** عند تنفيذ العامل → الحالة `EXPIRED`
  ويُرسل إشعار بأن الموعد فات. يمكنك حينها **إعادة الجدولة** من شاشة التفاصيل.

### 4. إعادة تشغيل الجهاز
- WorkManager قد يفقد الأعمال المجدولة زمنياً بعد إعادة التشغيل.
- `BootReceiver` يستمع لـ `BOOT_COMPLETED` → يقرأ التذكيرات بحالة `SCHEDULED`
  و`PENDING_NETWORK` → يعيد جدولتها جميعاً تلقائياً.

## 📊 حالات التذكير

| الحالة | المعنى |
|---|---|
| `SCHEDULED` | ⏰ مُجدول بانتظار الموعد |
| `PENDING_NETWORK` | 📡 حان الموعد لكن لا شبكة |
| `NOTIFIED` | 🔔 تم التنبيه بانتظار تفاعلك |
| `OPENED` | ✅ فتحت واتساب |
| `CANCELLED` | ❌ ألغيت التذكير |
| `EXPIRED` | ⚠️ فات الموعد (> 24 ساعة) |

## 📁 بنية المشروع (Clean Architecture)

```
domain/   → النماذج + واجهة المستودع + حالات الاستخدام (لا تعرف شيئاً عن Android)
data/     → Room (Entity/DAO/DB) + تنفيذ المستودع + ReminderWorker
di/       → وحدات Hilt (قاعدة البيانات، المستودع، العمّال)
util/     → الإشعارات، الجدولة، فتح واتساب، تنسيق التاريخ
receiver/ → BootReceiver لإعادة الجدولة
ui/       → Compose (main / add / detail) + Theme
```

> ملاحظة معمارية: الـ ViewModels لا تستدعي DAO مباشرة إطلاقاً، بل عبر UseCases → Repository.
