# مولّد أكواد التفعيل (Keygen) — Ed25519

نظام تفعيل بلا إنترنت، كل كود مربوط برقم الجهاز ومُوقّع بـ Ed25519.
التطبيق يحمل **المفتاح العامّ فقط** ويتحقّق محلياً. البذرة السرّية تبقى معك هنا فقط.

## المفتاح المضمَّن في التطبيق

```
PUB_B64 = CHS1vCGSq2GitGzMNt7d8+VkOWYVQghVOwQDfEMr5Bw=
```
موجود في `app/.../util/LicenseManager.kt`. آمن للنشر.

> ⚠️ **البذرة السرّية (SEED) لا تُوضَع في هذا المستودع ولا في التطبيق.**
> احتفظ بها في مكان خاصّ لديك. من يملك البذرة يستطيع توليد أي كود.

## المتطلبات

Node.js فقط (يستخدم `nacl.min.js` المجاور — لا يحتاج تثبيت أي حزمة).

## توليد كود لجهاز

المستخدم يفتح التطبيق فيظهر «رمز جهازك» (مثال: `ABCD-EFGH-JKLM-NPQR`).
تأخذ هذا الرمز وتولّد له كوداً:

```bash
# كود دائم
node keygen.mjs code --seed <البذرة_السرّية_64hex> --device ABCDEFGHJKLMNPQR --days 0

# كود مؤقّت (مثلاً 30 يوم)
node keygen.mjs code --seed <البذرة_السرّية_64hex> --device ABCDEFGHJKLMNPQR --days 30
```

الشرطات في رمز الجهاز اختيارية (المولّد والتطبيق يتجاهلانها). انسخ «الكود» الناتج
وأرسله للمستخدم؛ يُدخله في شاشة التفعيل مرة واحدة.

- `--days 0` = دائم (لا ينتهي).
- `--days N` = يعمل N يوماً من لحظة التفعيل (حارس ساعة يمنع إرجاع وقت الجهاز للوراء).
- `--prefix` الافتراضي `UNIV1` (يجب أن يطابق `PREFIX` في `LicenseManager.kt`).

## إنشاء زوج مفاتيح جديد (اختياري)

لو أردت مفتاحاً خاصاً بك بدل المضمَّن:

```bash
node keygen.mjs new
```
ثم ضع المفتاح العامّ في `LicenseManager.kt` → `PUB_B64`، واحتفظ بالبذرة سرّاً.

## استرجاع المالك

في شاشة التفعيل: اضغط ضغطة **مطوّلة** على أيقونة القفل ليظهر حقل «بذرة المالك».
أدخل البذرة السرّية (64 hex) ⇒ تفعيل دائم على هذا الجهاز مباشرة (للطوارئ فقط).
