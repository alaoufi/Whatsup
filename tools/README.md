# تفعيل التطبيق — Ed25519 (مربوط بمولّد المالك)

نظام تفعيل بلا إنترنت، كل كود مربوط برقم الجهاز ومُوقّع بـ Ed25519.
التطبيق يحمل **المفتاح العامّ فقط** ويتحقّق محلياً.

## المفتاح المضمَّن في التطبيق (نظام UNI3)

```
PUB_B64 = W5Kc9hRB7lb9xSh/VqdR4T8GT6VaDznEwYQgXZpLZz0=
PREFIX  = UNI3
```
موجود في `app/.../util/LicenseManager.kt`. آمن للنشر، ومطابق لمفتاح **مولّد المالك الموحّد**
(تطبيق `me.alaoufi.keygen` / `guard.js`). أي كود يخرج من مولّد المالك يُفعّل هذا التطبيق مباشرة.

> ⚠️ **البذرة السرّية (SEED) تبقى في مولّد المالك فقط** — ليست في هذا المستودع ولا في
> التطبيق. من يملك البذرة يستطيع توليد أي كود.

## توليد الأكواد

استخدم **مولّد المالك** نفسه (المقترن بالمفتاح أعلاه). المستخدم يرسل «رقم الجهاز»
الظاهر في التطبيق، فتولّد له كوداً وتُرسله له ليُدخله مرة واحدة.

> الملفّان `keygen.mjs` و `nacl.min.js` هنا مولّد **عامّ** (يأخذ البذرة كوسيط `--seed`)
> ولا يحملان أي مفتاح؛ للاستخدام العامّ فقط. الأكواد الحقيقية تُولَّد بمولّد المالك.

## المتطلبات (للمولّد العامّ فقط)

Node.js فقط (يستخدم `nacl.min.js` المجاور — لا يحتاج تثبيت أي حزمة).

## توليد كود لجهاز

المستخدم يفتح التطبيق فيظهر «رمز جهازك» (مثال: `ABCD-EFGH-JKLM-NPQR`).
تأخذ هذا الرمز وتولّد له كوداً:

```bash
# كود دائم
node keygen.mjs code --seed <البذرة_السرّية_64hex> --device ABCDEFGHJKLMNPQR --days 0

# كود مؤقّت (مثلاً 30 يوم)
node keygen.mjs code --seed <البذرة_السرّية_64hex> --device ABCDEFGHJKLMNPQR --days 30
```

الشرطات في رمز الجهاز اختيارية (المولّد والتطبيق يتجاهلانها). انسخ «الكود» الناتج
وأرسله للمستخدم؛ يُدخله في شاشة التفعيل مرة واحدة.

- `--days 0` = دائم (لا ينتهي).
- `--days N` = يعمل N يوماً من لحظة التفعيل (حارس ساعة يمنع إرجاع وقت الجهاز للوراء).
- `--prefix` يجب أن يطابق `PREFIX` في `LicenseManager.kt` (هنا `UNIV1`).

## الكود العالمي (كود واحد لأي جهاز)

التطبيق يقبل أيضاً **كوداً عالمياً** يُوقَّع على «جهاز» ثابت اسمه `UNIVERSAL`،
فيعمل على جميع الأجهزة بدون توليد كود لكل جهاز:

```bash
node keygen.mjs code --seed <البذرة_السرّية_64hex> --device UNIVERSAL --days 0
```

انسخ الناتج واستخدمه على أي جهاز. (ما زال محمياً بتوقيع Ed25519 — لا يُزوَّر بدون البذرة.)

## استرجاع المالك

في شاشة التفعيل: اضغط ضغطة **مطوّلة** على أيقونة القفل ليظهر حقل «بذرة المالك».
أدخل البذرة السرّية (64 hex) ⇒ تفعيل دائم على هذا الجهاز مباشرة (للطوارئ فقط).
